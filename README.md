# Testes com Devin

Este é um projeto de exemplo para aprender e praticar Git, GitHub e GitHub Actions com o Devin.

## Objetivo

Simular situações reais de trabalho utilizando:
- Git para controle de versão
- GitHub para colaboração
- GitHub Actions para CI/CD

## Estrutura do Projeto

- `scripts_ia/` - Scripts Python para exemplos de IA
- `templates_prompts/` - Templates de prompts reutilizáveis
- `example-project/` - Projeto JavaScript de exemplo
- `glossario_ia_completo.md` - Glossário completo de IA
- `INDEX_MATERIAIS.md` - Índice de materiais
- `recursos_portugues.md` - Recursos em português

## Configuração

Este projeto foi configurado para simular um ambiente de desenvolvimento real com:
- Branch strategy (main, develop, feature branches)
- Pull requests
- GitHub Actions para CI/CD
- Code review simulation
